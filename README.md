# 예약 사이트 제작 도우미

학교 예약 사이트를 브라우저에서 구성하고, 선택한 설정과 Firebase 실행 코드를 ZIP으로 내려받는 도구입니다.

## 사용

GitHub Pages의 도우미에서 기본 세트 → 디자인 → 일정·운영 → 신청 항목 → 기능·관리 → 설치 준비 순서로 구성합니다. 신청자·관리자 화면을 확인한 뒤 설치 ZIP을 내려받고, 각자 소유한 Firebase 프로젝트에 설치합니다. 새로고침하면 조립 중인 설정은 초기화됩니다.

로고는 브라우저에서 자동 축소합니다. 공휴일은 선택 연도에 맞춰 계산하며 실제 날짜 확인과 추가 제외일 입력을 지원합니다. 사용자 설정·로고·예약을 도우미 서버에 저장하지 않습니다. 웹폰트는 외부 CDN에서 불러옵니다.

## 개발

빌드 없이 index.html과 동봉한 JavaScript·CSS를 정적으로 제공합니다. GitHub Pages는 main 브랜치 루트에서 배포합니다. firebase-template은 다운로드되는 사이트의 원본입니다. 원본 또는 설치 안내를 수정한 뒤 `node scripts/build-package.cjs`로 package-assets.js를 다시 생성하세요.

## 검증 범위

도우미의 로컬 기능·용량 최적화·공휴일·설치 패키지 구성 검사를 수행했습니다. 실제 Firebase 보안 규칙 실행, 동시 신청 부하 및 전체 운영 흐름 검증은 진행 중입니다. 실사용 전 설치 체크리스트로 검증해야 합니다. 설치 사진은 실제 설치 검수 후 추가할 예정입니다.
