# 예약 사이트 제작 도우미 — 로컬 초안

index.html을 열면 도우미가 실행됩니다. Node.js가 있다면 이 폴더에서 `node serve.cjs` 실행 후 http://127.0.0.1:4187 로 접속할 수도 있습니다.

## 현재 구성
밝은 회색·화이트 바탕과 슬레이트 블루로 정리한 도우미입니다. 기본 세트 → 디자인 → 일정·운영 → 신청 항목 → 기능·관리 → 설치 준비 순서로 작업합니다. 첫 화면에는 새로 만들기만 제공하며, 저장한 구성 수정·설정 불러오기는 제거했습니다. 새로고침하면 조립 중인 내용과 가상 예약이 사라집니다.

학부모 상담·특별실·물품 대여·행사 기본 세트, 로고 업로드, 3가지 사이트 스타일, 5종 글꼴, 저채도 색상 선택을 제공합니다. 날짜/시간/교시 예약, 기간·요일 일괄 추가, 월별 달력, 신청 항목과 드롭다운, 드래그 정렬을 지원합니다.

관리자 미리보기는 운영 달력·예약 검색·일정 설정·사이트 설정·물품과 반납 관리로 구성합니다. 사이트 설정에서 신청 전·중·후 안내를 편집합니다. 활성 예약의 회차·물품 삭제와 정원·재고 축소를 검사하고, 신청 당시 항목·응답·회차는 스냅샷으로 보관합니다. 로컬 가상 데이터에서 검사한 보호 장치이며 영구 보존이나 실제 서비스 안전성을 보장하지 않습니다.

## 다운로드와 설치
코드 받기는 선택한 구성과 Firebase 실행 코드·보안 규칙·설정 도구·배포 명령·오프라인 설치 체크리스트를 ZIP으로 만듭니다. 단순 미리보기 HTML 다운로드가 아닙니다. Firebase 프로젝트 생성, Firestore, Authentication, 관리자 계정·권한 지정과 CLI 배포를 사용자가 수행해야 합니다. 설치 안내에는 직접 캡처한 콘솔 화면을 순차 추가하고 있습니다.

실제 Firebase 규칙 실행·저장·동시 신청·운영 배포 검증은 아직 완료하지 않았습니다. 관리자 Gmail 알림을 선택하면 설치 ZIP에 별도의 Google Apps Script 연결 안내가 포함됩니다. CSV 내려받기는 계속 사용할 수 있습니다. 로컬 미리보기의 데이터는 외부로 전송하지 않습니다. 웹폰트만 jsDelivr와 Google Fonts에서 로드합니다. 폰트 연결 실패 시 기본 글꼴을 표시합니다. 기존 운영 서비스·저장소·포트폴리오는 접근하거나 수정하지 않았습니다.

검사: 기본 동작 10개 + 관리자 보호 8개 + 패키지·모델 7개 통과. 실제 Firebase 실행과 동시 신청 검증은 미완료입니다.
